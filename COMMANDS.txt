SETUP - Run these once to prepare the environment:
================================================================================

# Navigate to project directory
cd c:\Users\pc\projects\MLEng-politicalparties-python-exercise

# Create virtual environment (if not already created)
C:/Users/pc/AppData/Roaming/uv/python/cpython-3.14.3-windows-x86_64-none/python.exe -m venv .venv

# Activate virtual environment
.venv\Scripts\activate

# Install pytest and test dependencies
.venv\Scripts\python.exe -m pip install pytest pytest-mock -q --break-system-packages

# Install core ML/data packages
.venv\Scripts\python.exe -m pip install pandas scikit-learn xgboost requests fastapi uvicorn streamlit -q --break-system-packages --no-deps


TESTING - Run these to verify the code works:
================================================================================

# Run all unit tests
.venv\Scripts\python.exe -m pytest tests/test_data_loader.py -v

# Run unit tests with short traceback
.venv\Scripts\python.exe -m pytest tests/test_data_loader.py -v --tb=short

# Run prediction test (demonstrates the model)
.venv\Scripts\python.exe test_predictions.py

# Run all tests together
.venv\Scripts\python.exe -m pytest tests/ -v

RUNNING SERVICES (for Docker Compose deployment):
================================================================================

# Build and run services
cd src
docker-compose build

# Start services in foreground
docker-compose up

# Start services in background
docker-compose up -d

# Stop services
docker-compose down

# View service logs
docker-compose logs -f

# Access services:
#   - Streamlit app: http://localhost:8501

#   - API docs: http://localhost:8000/docs
